# الواجهة الأمامية

يستضيف هذا الدليل واجهات الويب الخاصة بـ Fruitful.

## التطبيقات الفرعية

- `app/` – موقع مبني بـ Next.js يوفّر واجهة المستخدم الرئيسية.
- `chat-ui/` – واجهة محادثة مبنية باستخدام Vite وReact. راجع [chat-ui/ARCHITECTURE.md](chat-ui/ARCHITECTURE.md) للاطلاع على تفاصيل البنية المعمارية.

## متغيرات البيئة

يعتمد كلا التطبيقين الفرعيين على متغيرات البيئة للتواصل مع خدمات الواجهة الخلفية.

### Next.js (`app/`)

- `NEXT_PUBLIC_BACKEND_URL` – عنوان URL الأساسي لطلبات API الخاصة بالواجهة الخلفية.
- `NEXT_PUBLIC_API_KEY` – مفتاح API المستخدم لتفويض الطلبات الصادرة من موقع Next.js.
- `NEXT_PUBLIC_APPSYNC_GRAPHQL_ENDPOINT` – عنوان URL لنقطة نهاية AppSync GraphQL.
- `NEXT_PUBLIC_APPSYNC_API_KEY` – مفتاح API لطلبات AppSync.

### واجهة المحادثة (`chat-ui/`)

- `VITE_API_BASE_URL` – عنوان URL الأساسي لواجهة API التي تستخدمها واجهة المحادثة.
- `VITE_API_KEY` – مفتاح API الذي تستخدمه واجهة المحادثة.
